# Drafts — Unpublished, Not for Citation

Files in this folder are **works in progress**. They contain incomplete derivations, unresolved gaps, or claims that have not been substantiated with the rigor required for publication. **Do not cite as EGT positions.** They are preserved here so revisions can proceed transparently.

When (and if) a draft is completed to publication standard, it will be moved out of this folder into `theory/`, `empirical/`, or `predictions/` as appropriate, and the corresponding version will be published on Zenodo.

## Discipline for drafts

Going forward, any draft entering this folder must have:
1. A **DRAFT** watermark or clear header on the first page.
2. A `README.md` alongside the file listing the known gaps.
3. Explicit statement of what would move it into `theory/` or `predictions/`.
